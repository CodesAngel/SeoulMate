Daily "Guess the drama": current and proposed

Today nothing on the site changes from one day to the next unless the fan searches, so there's no reason to come back daily (the home picks rotate, but quietly). The proposal is a five-question picture quiz, the same for everyone each day, with a streak and a result fans can paste into a chat. It uses the 144 labelled pictures in quiz/ and real poster close-ups.

1. The quiz page like Wordle: one a day, same for everyone, shareable squares

  • Picture questions use the labelled images in quiz/ (fan art and stills; not copied into this mockup).
  • Four choices: the answer plus three dramas of the same genre and years, never a season of the same show.
  • Tap a choice in the mock.
  • The wrong pick turns red, the right one green, the rest fade.
  • A card shows the right drama with View drama and My list: every miss is a recommendation.
  • The progress bar keeps a red segment for this question.
  • Poster close-ups are a crop of a real poster from a drama with 20k+ watchers. The crop avoids the top and bottom thirds, where titles usually sit.
  • These make the supply endless; the 144 pictures alone last about four weeks.
  • The full poster is revealed. If the drama is already in the fan's list, the button says so.
  • Score, squares and streak. Share result opens the phone's share sheet; Copy copies the text in the box.
  • The list of the five answers links to each drama.
  • The streak (side card) counts days in a row: Wednesday was missed, so Thursday to today is 5.

What changes

  1. A new page, /quiz: one card with the date, streak, a 5-part progress bar, the picture, the question and four answers. On a computer a 320 px side column holds the week's streak, Practice mode and the rules; on a phone only the streak card stays, below.
  2. Each day: 3 picture questions and 2 poster close-ups, picked by a seed from the date, so everyone gets the same five.
  3. Answers are 52 px tall buttons in two columns on a computer and one column on a phone.
  4. Result: score, coloured squares, a share text ("SeoulMate Daily #12 4/5 🔥5"), the five answers, and a countdown to the next quiz.
  5. Practice mode keeps the category quiz planned in quiz/README.md: Cartoon 69, Historical 47, Reference 28, and endless poster close-ups.
  6. Entry points: a "Today's quiz" link on the home page and in the menu (to be designed with the home page).

Details

  • Images go into a new public Storage bucket, quiz-images. labels.json becomes a table, quiz_items (id, type cartoon / historical / reference / poster_crop, image path, drama_id, crop box).
  • Endpoints: GET /quiz/daily?date= returns 5 questions without answers; POST /quiz/daily/answer checks one. The answers aren't in the page source.
  • Streaks: guests keep theirs in localStorage; signed-in fans get quiz_results (user_id, quiz_date, score, time_ms), one row per day.
  • Rights: the pictures are fan art and stills owned by others. Credit the artists, or launch with poster close-ups only.
  • Labels must be checked before launch; one wrong answer key spoils a day.

Cost

  • Five small reads a day per player; the daily set can be cached for the whole day.
  • Poster crops are made once per question and stored (a few KB each).
  • No search or ranking change.
  • Size M, after the labels are checked (Phase 0 in quiz/README.md).
